# Dragonfire: Dani's Reign
An original dark-fantasy twin-stick arcade shooter. Ride your dragon as Dani, breathe fire, and bring down Ashwing the Black.
Single HTML file, no dependencies. Play: https://tmacgoat.github.io/dragonfire/
Controls: WASD + mouse, PS5/Xbox controller, or touch twin-sticks on phones. Installable (Add to Home screen).
